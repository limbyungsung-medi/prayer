쉬지 않는 기도

개인 기도노트 웹앱 · 시행일 2026년 11월 8일

개인정보처리방침

"쉬지 않는 기도"(이하 "앱")는 개인 기도 생활을 돕기 위한 무료 웹앱입니다. 앱은 운영자가 이용자의 정보를 수집하거나 보관하는 서버를 두지 않습니다.

1. 기록이 저장되는 곳

이용자가 입력한 사람·연락처·기도제목·말씀노트 등 모든 기록은 이용자의 기기(브라우저 저장소) 안에만 저장됩니다. 운영자는 이 기록에 접근할 수 없습니다.

2. 연락처 가져오기

이용자가 연락처 파일(VCF)을 고르면, 파일은 이용자의 기기 안에서만 읽히며 어디에도 전송되지 않습니다.

3. 구글 드라이브 동기화 (선택)

  • 이용자가 동기화를 켠 경우에만, 기록을 이용자 본인의 구글 드라이브에 파일 하나로 저장합니다.
  • 앱이 요청하는 권한은 drive.file 하나뿐이며, 앱이 직접 만든 그 파일 외에 이용자 드라이브의 다른 파일은 보거나 바꿀 수 없습니다.
  • 파일은 저장 전에 이용자가 정한 비밀 문구로 암호화(AES-GCM)되므로, 비밀 문구 없이는 내용을 읽을 수 없습니다. 비밀 문구는 이용자 기기에만 저장되며 운영자에게 전송되지 않습니다.
  • 구글 계정 정보(이름·이메일 등)는 앱이 수집하거나 저장하지 않습니다. 구글 로그인 과정은 구글의 개인정보처리방침을 따릅니다.
  • 앱이 구글 API로 받은 정보는 동기화 기능을 제공하는 데에만 쓰이며, 다른 곳에 전송·판매·공유하지 않습니다. 앱의 구글 사용자 데이터 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

4. 기록 삭제

브라우저(또는 홈 화면 앱)의 사이트 데이터를 지우면 기기 안의 기록이 삭제됩니다. 구글 드라이브의 동기화 파일("쉬지않는기도_동기화.json")은 이용자가 드라이브에서 직접 지울 수 있으며, 구글 계정 설정의 "타사 앱 및 서비스"에서 앱의 접근 권한을 언제든 해제할 수 있습니다.

5. 외부 연결

전화·문자·카카오톡 보내기는 이용자가 직접 누를 때만 기기의 해당 앱을 엽니다. 앱은 메시지 내용을 저장하거나 전송하지 않습니다.

이용약관

  1. 앱은 개인과 교회 공동체의 기도 생활을 돕기 위해 무료로 제공됩니다.
  2. 앱에 입력하는 기도제목 가운데 다른 사람에 관한 내용은 그분의 사적인 이야기이므로, 이용자는 이를 기도 목적에 맞게 조심스럽게 다룹니다.
  3. 기록은 이용자 기기와 이용자 본인의 구글 드라이브에만 있으므로, 백업과 비밀 문구 관리는 이용자의 책임입니다. 비밀 문구를 잊으면 드라이브의 동기화 파일을 열 수 없습니다.
  4. 앱은 있는 그대로 제공되며, 운영자는 기기 고장·데이터 손실 등으로 생긴 손해에 대해 책임지지 않습니다.

English summary

"쉬지 않는 기도" (Pray Without Ceasing) is a free personal prayer-journal web app. It has no server: all data stays on the user's device. If the user turns on Google Drive sync, the app uses only the drive.file scope to store one file it creates in the user's own Drive, encrypted with a passphrase known only to the user. The app does not collect, sell, or share any personal data or Google user data, and its use of Google user data adheres to the Google API Services User Data Policy, including the Limited Use requirements.
